1.Ruff、mypy、pytest 分别解决什么问题，为什么不能互相替代?
答：Ruff检查代码格式与静态代码规则，mypy检查参数、返回值、空值以及对象之间的类型关系，pytest运行单元测试，三个分工不同不可替代。
2.print("debug") 为什么被 T201 阻断。
答：后端代码规范中不能单独打印无结构化字段的字符串，可能会导致泄露token或者密钥、没有info、worning、error等这些日志级别
3.assert False 如何证明 pytest 能阻断失败。
答：断言后的布尔值为false会抛出错误阻断pytest测试。
4.uv.lock 与 uv sync --frozen 如何保证环境复现。
答：uv.lock文件记录已经解析出的精确依赖版本、来源、哈希和平台条件，uv sync --frozen不更改锁文件的情况下将锁文件中规定的依赖进行安装保证稳定复现。
5.当前永久测试保障了什么，又没有保障什么。
答：当前永久测试主要防止源码版本号与发行包元数据发生漂移，同时证明包可以导入、发行元数据可以读取以及 pytest 测试链路能够运行。但它只验证包元数据一致性，不代表 API、数据库、权限、安全和其他业务逻辑已经得到测试，也不能替代构建、干净环境安装和跨平台 CI 测试。
